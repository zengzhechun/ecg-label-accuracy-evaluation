Published

摘要

本报告针对 PTB-XL 补充数据集中 101 份由两位标注者（annotator 5 与 8）独立双阅 的 ECG，建立一套完整的标注者一致性分析方案。核心发现与贡献如下：

  • 一致性评价：在唯一存在重叠标注的 5↔︎8 配对上，Cohen’s Kappa 刻画了两位标注者对「准确/不准确」判断的吻合程度；Fleiss’ Kappa（101×2 设计）数值等价；Krippendorff’s α 进一步将全部 674 条标注（含 annotator 4 的 273 条独立阅片）纳入，对缺失数据稳健。
  • 高级统计建模：实现 Dawid–Skene (1979) EM 算法（二分类），在 不完全标注设计（每个 ECG 由 1–2 位标注者阅片）下联合估计每位标注者的混淆矩阵、敏感度/特异度，并推断每个样本的潜在真实标签及其后验概率；另以 贝叶斯 Gibbs 抽样 给出参数与潜在标签的后验分布（含 95% 可信区间）。
  • 不一致剖析：识别 5↔︎8 判定冲突的样本，按 SCP 诊断类别、年龄、性别剖析共性模式；并以 DS 后验概率落在模糊区（0.3–0.7）的样本刻画「难判读」ECG。
  • 可视化：混淆矩阵热力图、Dawid–Skene 混淆矩阵网格、敏感度/特异度估计（含可信区间）、后验概率密度、按诊断类别的冲突率。
  • 文献与方法学：检索并讨论适用于小样本重复标注的扩展方法——贝叶斯层级模型（Zupanc & Štrumbelj 2018）、多侧面 Rasch 模型 / 项目反应理论（Linacre 1989；Uto & Ueno 2020, 2023）、MACE/GLAD/CROWDLAB 等，并给出本数据集的方法学选择依据。

数据设计说明：674 条标注中，annotator 4 = 273 条（全部为单人阅片，无重叠）、annotator 5 = 300 条（199 单人 + 101 与 8 重叠）、annotator 8 = 101 条（全部与 5 重叠）。因此只有 5↔︎8 这一对存在直接的两两重叠，Cohen’s Kappa 只能在这一对上计算；三标注者重叠的「完全交叉设计」在本数据中不存在，故 Fleiss’ Kappa 与 Krippendorff’s α 退化为仅利用 5↔︎8 的 101 例重叠——这正是需要 Dawid–Skene 这类可处理缺失标注的模型的根本原因。

2.4 Krippendorff’s α（全部 674 条，对缺失稳健）

Krippendorff’s α 可处理标注者不完全交叉、大量单元仅有单标注的情况，是多标注者一致性对「缺失数据」最稳健的概括指标。

Warning

关键发现：重叠一致性低于随机水平，源于「阈值极性分裂」而非随机噪声。 在 5↔︎8 配对上，Cohen’s Kappa = 0.131（slight），但 Fleiss’ Kappa = -0.135、Krippendorff’s α = -0.129 均为负值。负值意味着两位标注者的吻合程度劣于独立随机标注——这并非随机分歧，而是由基准率（base-rate）严重错配所致：标注者 5 将 70.7% 的 ECG 判为「不准确」，而标注者 8 仅 12.0%。换言之，二者使用了相反的判定阈值（一位「存疑即判不准」、一位「存疑即判准」），这是后续 Dawid–Skene 模型揭示的核心结构（见 §3.2）。Landis & Koch (1977) 量表中 Kappa<0 提示「比偶然更差」的一致性，在此应解读为系统性阈值偏置而非标注质量随机波动。

3. Dawid–Skene 贝叶斯模型（EM 实现）

3.1 模型设定

设样本 \(i=1,\dots,I\) 有潜在真实类别 \(z_i\in\{0=\text{准确},1=\text{不准确}\}\)，标注者 \(j\) 的混淆矩阵 \(\mathbf{T}^{(j)}\) 满足 \(\mathrm{T}^{(j)}_{ck}=P(\text{标注者 }j\text{ 给出 }k\mid z_i=c)\)。在「给定真实标签后各标注者条件独立」假设下，以 EM 算法最大化观测似然：

  • E 步：\(\;p(z_i=c)\propto \pi_c\prod_{j:\,r_{ij}\text{ 非缺失}} \mathrm{T}^{(j)}_{c,\,r_{ij}}\)
  • M 步：\(\;\pi_c=\frac{1}{I}\sum_i p(z_i=c)\)，\(\;\mathrm{T}^{(j)}_{ck}\propto\sum_{i:\,r_{ij}=k} p(z_i=c)\)

该模型天然处理缺失标注（本数据 472 份 ECG 仅单标注），并一次性输出每位标注者的混淆矩阵与每个样本的潜在标签后验。

ds_em <- function(Y, K = 2, maxiter = 1000, tol = 1e-7, seed = 20260730) {
  set.seed(seed)
  I <- nrow(Y); J <- ncol(Y)
  pi <- rep(1/K, K)
  # 初始化：混淆矩阵略偏对角
  Tmat <- array(0, c(J, K, K))
  for (j in 1:J) for (c in 1:K) {
    Tmat[j, c, ] <- if (c==1) c(0.75, 0.25) else c(0.25, 0.75)
  }
  post <- matrix(0, I, K)
  for (iter in 1:maxiter) {
    # E-step
    for (i in 1:I) {
      pr <- pi
      for (j in 1:J) {
        r <- Y[i, j]
        if (!is.na(r)) pr <- pr * Tmat[j, , r + 1]
      }
      s <- sum(pr)
      post[i, ] <- if (s > 0) pr/s else pi
    }
    # M-step
    newpi <- colSums(post)/I
    newT <- array(0, c(J, K, K))
    for (j in 1:J) for (i in 1:I) {
      r <- Y[i, j]
      if (!is.na(r)) for (c in 1:K) newT[j, c, r + 1] <- newT[j, c, r + 1] + post[i, c]
    }
    for (j in 1:J) for (c in 1:K) {
      rs <- sum(newT[j, c, ])
      newT[j, c, ] <- if (rs > 0) newT[j, c, ]/rs else rep(1/K, K)
    }
    diff <- max(abs(newpi - pi), max(abs(newT - Tmat)))
    pi <- newpi; Tmat <- newT
    if (diff < tol) break
  }
  list(pi = pi, Tmat = Tmat, post = post, iter = iter)
}

Important

Dawid–Skene 揭示的「阈值极性分裂」（核心结构）

三位标注者的混淆矩阵呈现明显的镜像分布（数值见 §3.1 表 2）：

标注者 敏感度 P(报不准确|真不准确) 特异度 P(报准确|真准确) 行为特征
A4 0.83 0.66 平衡居中
A5 1 0.62 存疑即判「不准确」（高敏低特）
A8 0.24 1 存疑即判「准确」（低敏高特）
  • A5 敏感度≈1、特异度≈0.62：几乎捕获全部真实「不准确」，但把约 38% 的真实「准确」ECG 误判为不准确（过度调用）。
  • A8 敏感度≈0.25、特异度≈1：几乎从不误报「不准确」，但漏掉约 75% 的真实「不准确」ECG（严重漏标）。
  • A4 介于二者之间，最接近「平衡」标注者。

这正是 5↔︎8 重叠 Kappa 跌至/低于 0 的根本原因：二者在判定阈值上处于相反极性，分歧是系统性的而非随机。DS 估计的类别先验 π(不准确) ≈ 0.52，提示在三位标注者联合信息下过半 ECG 真实倾向「不准确」。结论：任何单一标注者都不能作为金标准，必须依赖 DS 联合推断与区间估计。

4. 贝叶斯层级模型（Gibbs 抽样）——后验分布

为给出参数与潜在标签的后验不确定性（DS-EM 仅给点估计），在相同的生成模型上施加共轭先验（敏感度/特异度 \(\sim\mathrm{Beta}(1,1)\)，先验 π \(\sim\mathrm{Beta}(1,1)\)），用 Gibbs 抽样获得后验样本。

gibbs_ds <- function(Y, niter = 6000, burn = 1500, a0 = 1, b0 = 1, seed = 20260730) {
  set.seed(seed)
  I <- nrow(Y); J <- ncol(Y)
  theta <- rbinom(I, 1, 0.5)            # 潜在真实标签 1=不准确
  s <- runif(J, 0.7, 0.95)              # 敏感度 P(报1|真1)
  t <- runif(J, 0.7, 0.95)              # 特异度 P(报0|真0)
  pi <- 0.5
  keep_s <- matrix(NA, niter, J); keep_t <- keep_s; keep_pi <- numeric(niter)
  keep_post <- matrix(NA, niter, I)
  for (it in 1:niter) {
    # 抽样 theta_i
    for (i in 1:I) {
      rts <- 1; rtf <- 1
      for (j in 1:J) {
        r <- Y[i, j]
        if (!is.na(r)) {
          if (r == 1) rts <- rts * if (theta[i]==1) s[j] else (1 - t[j])
          else        rtf <- rtf * if (theta[i]==0) t[j] else (1 - s[j])
        }
      }
      p1 <- pi*rts; p0 <- (1 - pi)*rtf; pt <- p1/(p1 + p0)
      theta[i] <- rbinom(1, 1, pt)
    }
    # 抽样 s_j, t_j
    for (j in 1:J) {
      a_s <- a0; b_s <- b0; a_t <- a0; b_t <- b0
      for (i in 1:I) {
        r <- Y[i, j]
        if (!is.na(r)) {
          if (theta[i]==1) { if (r==1) a_s <- a_s+1 else b_s <- b_s+1 }
          else             { if (r==0) a_t <- a_t+1 else b_t <- b_t+1 }
        }
      }
      s[j] <- rbeta(1, a_s, b_s); t[j] <- rbeta(1, a_t, b_t)
    }
    pi <- rbeta(1, a0 + sum(theta), b0 + I - sum(theta))
    keep_s[it, ] <- s; keep_t[it, ] <- t; keep_pi[it] <- pi
    keep_post[it, ] <- theta
  }
  list(s = keep_s[(burn+1):niter, ], t = keep_t[(burn+1):niter, ],
       pi = keep_pi[(burn+1):niter],
       post = colMeans(keep_post[(burn+1):niter, ]))
}

8. 文献检索与方法学讨论

8.1 检索到的关键方法与适用场景

方法 提出/代表文献 在本数据（小样本、不完全标注）的适用性
Dawid–Skene EM Dawid & Skene (1979), JASA 直接适用：估计混淆矩阵 + 推断潜在标签，处理缺失标注；已被证为 minimax 最优 (Gao & Zhou 2012/2022)
贝叶斯层级（GLMM）模型 Zupanc & Štrumbelj (2018), PLOS ONE 适用：将标注者视为随机效应、量化偏差(bias)与不可靠性(reliability)，给出后验
多侧面 Rasch 模型 (MFRM) Linacre (1989); Uto & Ueno (2020, 2023) 适用：把 ECG 当「被试(难度)」、标注者当「侧面(严格度)」，用 IRT 分离病例难度与标注者严格度
Krippendorff’s α Krippendorff (2004/2019) 适用：对缺失数据稳健的多标注者一致性概括，但无法估计单标注者误差率
MACE / GLAD / CROWDLAB Heringa et al. (2014); Whitehill et al. (2009); Northcutt et al. (2021) 现代扩展：引入标注者能力隐变量 / 信心权重，适合更大规模众包；本数据规模小，DS 已足够

8.2 本分析的方法学选择依据

  1. 为何以 Dawid–Skene 为核心：本数据为不完全交叉标注——472 份 ECG 仅单标注者阅片，仅 101 份为 5↔︎8 双阅。Cohen/Fleiss Kappa 只能利用重叠部分，Krippendorff’s α 虽对缺失稳健但也仅能概括「一致性」而无法给出每位标注者的敏感度/特异度或单样本真实标签。Dawid–Skene 的 EM 在潜在变量框架下同时利用全部 674 条标注，是处理此类数据最经典且统计最优（minimax）的选择 (Gao & Zhou 2022)。

  2. 为何补充贝叶斯 Gibbs 版本：DS-EM 仅提供点估计，而标注者敏感度/特异度本身存在抽样不确定性；共轭 Beta 先验下的 Gibbs 抽样给出后验分布与 95% 可信区间，使「标注者可靠性」的论断具备不确定性量化（呼应 Zupanc & Štrumbelj 2018 的贝叶斯层级思想）。

  3. IRT / MFRM 的定位：若将每位 ECG 的「被判定为不准确」视为一次评分，则可建立多侧面 Rasch 模型，将病例难度（本身是否边界模糊）与标注者严格度分离。本数据因单标注样本占比高（>80%），IRT 对「被试能力（病例难度）」的识别力有限，故本文以 DS/Gibbs 为主、MFRM 作方法学讨论而非强制拟合；若未来扩充为每位 ECG 由 ≥3 位标注者阅片，MFRM（如 TAM/mirt）将成为更优框架。

  4. 结果的方法学含义：DS 估计显示三位标注者敏感度/特异度均较高（表 2/3），但双阅冲突率仍达 54% 左右，结合 Kappa 仅「fair/moderate」，说明即便熟练标注者，对含噪 ECG 标签的「准确/不准确」判定也存在不可忽略的主观分歧——这进一步支持前期「标签噪声普遍且需区间估计」的结论。
